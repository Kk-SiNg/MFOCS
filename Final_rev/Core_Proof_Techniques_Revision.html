1. Primitives, Definitions & Domain Boundaries pp. 151, 155–157

Every proof in this section depends on turning informal claims into exact algebraic or existential definitions and tracking where the domain starts and ends:

  • Even and odd integers (p. 151): An integer n n n is even if ∃ k ∈ Z \exists k \in \mathbb{Z} ∃k∈Z such that n = 2 k = 2 k + 0 n = 2k = 2k + 0 n=2k=2k+0, and odd if ∃ k ∈ Z \exists k \in \mathbb{Z} ∃k∈Z such that n = 2 k + 1 n = 2k + 1 n=2k+1.

  • Perfect square (p. 153): An integer m m m is a perfect square if ∃ i ∈ Z \exists i \in \mathbb{Z} ∃i∈Z such that m = i 2 m = i^2 m=i2.
  • Rational number in lowest terms (p. 156): Writing a rational number as p q \frac{p}{q} qp​ requires p ∈ Z p \in \mathbb{Z} p∈Z, q ≠ 0 q \ne 0 q=0, and gcd ⁡ ( p , q ) = 1 \gcd(p,q) = 1 gcd(p,q)=1. Omitting the reduced-fraction condition removes the contradiction when both p p p and q q q turn out to be even.
  • Mathematical induction schema (p. 157): For a predicate P ( n ) P(n) P(n) over integers starting at 1 1 1, the notes write the rule of inference as:

  • Base case fixes the starting integer: Although the handwritten heading on p. 157 mentions n ∈ Z n \in \mathbb{Z} n∈Z before starting at 1 1 1, proving P ( 1 ) P(1) P(1) and ∀ k ≥ 1   [ P ( k ) ⇒ P ( k + 1 ) ] \forall k \ge 1\,[P(k) \Rightarrow P(k+1)] ∀k≥1[P(k)⇒P(k+1)] establishes P ( n ) P(n) P(n) for n ≥ 1 n \ge 1 n≥1 only—not for n ≤ 0 n \le 0 n≤0.

3. Mental-Model Reset: Resolving Confused Layers pp. 154, 157–160

Most mistakes in direct, contrapositive, and inductive proofs happen when two distinct logical layers get mixed together:

Layer 1 vs. Layer 2: Algebraic Direction (p. 154)

Direct direction: Unpacking 3 n + 2 = 2 k + 1 3n+2 = 2k+1 3n+2=2k+1 traps n n n inside 3 n + 1 = 2 k 3n+1 = 2k 3n+1=2k.

Reversed direction: Assuming n = 2 k n = 2k n=2k puts the simple variable on the input side, so 3 ( 2 k ) + 2 = 2 ( 3 k + 1 ) 3(2k)+2 = 2(3k+1) 3(2k)+2=2(3k+1) requires zero division.

Global Target vs. Local Link in Induction (pp. 157–158)

Global target: ∀ n ≥ n 0 ,   P ( n ) \forall n \ge n_0,\, P(n) ∀n≥n0​,P(n) (never assumed).

Local conditional: Fix one k ≥ n 0 k \ge n_0 k≥n0​, assume P ( k ) P(k) P(k) just for that k k k, and prove P ( k + 1 ) P(k+1) P(k+1). (Avoid reusing n n n in the IH as p. 158 does; write k k k.)

True Base vs. Broken First Domino Link (pp. 159–160)

Wrong start: 2 n < n ! 2^n < n! 2n<n! step works for k ≥ 2 k \ge 2 k≥2, yet P ( 1 ) , P ( 2 ) , P ( 3 ) P(1), P(2), P(3) P(1),P(2),P(3) are false.

Broken link: Same-color balls has a true P ( 1 ) P(1) P(1) and valid step for k ≥ 2 k \ge 2 k≥2, but fails at k = 1 k = 1 k=1.

Why Induction Is Not Circular Reasoning (pp. 157–158)

In the inductive step, you do not assume "the theorem is true for all integers." You prove an implication P ( k ) ⇒ P ( k + 1 ) P(k) \Rightarrow P(k+1) P(k)⇒P(k+1) for an arbitrary fixed k ≥ n 0 k \ge n_0 k≥n0​. Together with the concrete anchor P ( n 0 ) P(n_0) P(n0​), those links build a finite chain P ( n 0 ) ⇒ P ( n 0 + 1 ) ⇒ ⋯ ⇒ P ( n ) P(n_0) \Rightarrow P(n_0+1) \Rightarrow \cdots \Rightarrow P(n) P(n0​)⇒P(n0​+1)⇒⋯⇒P(n) reaching every n ≥ n 0 n \ge n_0 n≥n0​. If even one link fails—especially the very first link k = n 0 k = n_0 k=n0​—the entire chain disconnects.
