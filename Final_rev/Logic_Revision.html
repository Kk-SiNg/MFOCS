1. Propositions & Connectives pp. 126–133

Proposition: A declarative statement that can be assigned a fixed truth value of True (1) or False (0), never both.

  • 1+1=21+1=21+1=2 (1) and 1+1=31+1=31+1=3 (0) are propositions.
  • "This statement is false." is not a proposition (self-contradictory; crossed out on p. 127).
  • "Today is Monday." requires a fixed day/context to hold a definite truth value.
  • Propositional variables (p,q,r,s,…p, q, r, s, \dotsp,q,r,s,…) stand for propositions.

Critical Trap: Implication vs. Contrapositive vs. Inverse (pp. 130–131)
  • p⇒qp \Rightarrow qp⇒q is False ONLY when p=1p=1p=1 and q=0q=0q=0. Whenever p=0p=0p=0, it is automatically 1.
  • Contrapositive (¬q⇒¬p\neg q \Rightarrow \neg p¬q⇒¬p): Always logically equivalent to p⇒qp \Rightarrow qp⇒q (identical truth-table columns on p. 130).
  • Inverse (¬p⇒¬q\neg p \Rightarrow \neg q¬p⇒¬q) and Converse (q⇒pq \Rightarrow pq⇒p): NOT equivalent to p⇒qp \Rightarrow qp⇒q. Class example (p. 131): "जल है तो कल है" (p⇒qp \Rightarrow qp⇒q) does not equal "जल नहीं तो कल नहीं" (¬p⇒¬q\neg p \Rightarrow \neg q¬p⇒¬q) — they disagree when p=0,q=1p=0, q=1p=0,q=1.

Compound Propositions pp. 132–133

If p,qp, qp,q are propositions, combining them with ¬,∨,∧,⊕,⇒,⇔\neg, \lor, \land, \oplus, \Rightarrow, \Leftrightarrow¬,∨,∧,⊕,⇒,⇔ produces compound propositions. Always evaluate parentheses inside-out, e.g.:

((¬p∧q)∨r)⇒s.\bigl((\neg p \land q) \lor r\bigr) \Rightarrow s.((¬p∧q)∨r)⇒s.

2. Tautology, Contradiction, Satisfiability & Equivalence pp. 130, 135, 142

Classify any formula by checking its final column across every truth assignment to its underlying variables:

Tautology (Valid Formula)

Evaluates to 1 in every row of its truth table. Never false.

Ex: p∨¬pp \lor \neg pp∨¬p, or ((p⇒q)∧p)⇒q\bigl((p\Rightarrow q)\land p\bigr)\Rightarrow q((p⇒q)∧p)⇒q.

Contradiction

Evaluates to 0 in every row of its truth table. Never true.

Ex: p∧¬pp \land \neg pp∧¬p.

Satisfiable

Evaluates to 1 in at least one row. (Every tautology is satisfiable, not vice versa.)

Class Example (p. 142): Satisfiable vs. Valid

Consider ((p∧q)∨¬r)⇒q\bigl((p \land q) \lor \neg r\bigr) \Rightarrow q((p∧q)∨¬r)⇒q:

  • Satisfiable? Yes: Any assignment with q=1q = 1q=1 makes the consequent 1, so the implication is 1.
  • Valid (Tautology)? No: Set p=0,q=0,r=0p=0, q=0, r=0p=0,q=0,r=0. Then (0∧0)∨1=1(0 \land 0) \lor 1 = 1(0∧0)∨1=1, while q=0q=0q=0, giving 1⇒0=01 \Rightarrow 0 = 01⇒0=0.

Logical Equivalence (A≡BA \equiv BA≡B): AAA and BBB have the same truth value in every row (equivalently A⇔BA \Leftrightarrow BA⇔B is a tautology). Essential equivalences:

  • Contraposition: (p⇒q)≡(¬q⇒¬p)(p \Rightarrow q) \equiv (\neg q \Rightarrow \neg p)(p⇒q)≡(¬q⇒¬p)
  • De Morgan's Laws: ¬(p∧q)≡¬p∨¬q\neg(p \land q) \equiv \neg p \lor \neg q¬(p∧q)≡¬p∨¬q and ¬(p∨q)≡¬p∧¬q\neg(p \lor q) \equiv \neg p \land \neg q¬(p∨q)≡¬p∧¬q
  • Biconditional split: (p⇔q)≡(p⇒q)∧(q⇒p)(p \Leftrightarrow q) \equiv (p \Rightarrow q) \land (q \Rightarrow p)(p⇔q)≡(p⇒q)∧(q⇒p)

3. Arguments, Validity & Soundness pp. 134–146

An argument (inference) consists of premises P1,P2,…,PnP_1, P_2, \dots, P_nP1​,P2​,…,Pn​ and one conclusion ccc:

P1, P2, …, Pncwritten also as(P1∧P2∧⋯∧Pn)⊢c.\frac{P_1,\ P_2,\ \dots,\ P_n}{c} \qquad\text{written also as}\qquad (P_1 \land P_2 \land \dots \land P_n) \vdash c.cP1​, P2​, …, Pn​​written also as(P1​∧P2​∧⋯∧Pn​)⊢c.
Clearing Up the "Which Premise to Assign True?" Confusion

Always separate the two layers:

  1. Layer 1 — Atomic Variables (p,q,r,s,T,u,…p, q, r, s, T, u, \dotsp,q,r,s,T,u,…): These are the inputs you assign 0 or 1 to.
  2. Layer 2 — Premises (P1,…,PnP_1, \dots, P_nP1​,…,Pn​): Each premise is a compound formula built from those variables. You never assign True/False to a premise independently of its variables — once variables get 0/1, every premise's truth value is fixed.

Why only "all premises = 1" rows matter for validity: If even one premise evaluates to 0, then P1∧⋯∧Pn=0P_1 \land \dots \land P_n = 0P1​∧⋯∧Pn​=0, so (0⇒c)=1(0 \Rightarrow c) = 1(0⇒c)=1 automatically. The implication (P1∧⋯∧Pn)⇒c(P_1 \land \dots \land P_n) \Rightarrow c(P1​∧⋯∧Pn​)⇒c can ONLY fail on a variable assignment where every premise evaluates to 1 and ccc evaluates to 0.

  • Valid Argument (pp. 135, 139): No assignment to the underlying variables makes all premises 1 while making ccc equal 0 — i.e., (P1∧P2∧⋯∧Pn)⇒c(P_1 \land P_2 \land \dots \land P_n) \Rightarrow c(P1​∧P2​∧⋯∧Pn​)⇒c is a tautology.
  • Sound Argument (p. 141): Valid and all of its premises are actually true.
  • Contradictory Premises Note: If no variable assignment can make every Pi=1P_i = 1Pi​=1 simultaneously (e.g., ppp and ¬p\neg p¬p), then P1∧⋯∧PnP_1 \land \dots \land P_nP1​∧⋯∧Pn​ is always 0, making 0⇒c0 \Rightarrow c0⇒c always 1 — technically valid, yet unsound.

Two Ways to Test Any Argument

Method A — Counterexample Search (assigning variables backwards from c=0c=0c=0)

Goal: Try to find one variable assignment making c=0c = 0c=0 and every premise Pi=1P_i = 1Pi​=1. If one exists ⇒ INVALID. If impossible ⇒ VALID.

  • Class Example 1 (p. 137): p⇒q, qp\dfrac{p \Rightarrow q,\ q}{p}pp⇒q, q​. To get c=p=0c = p = 0c=p=0, set p=0p = 0p=0. To make premise 2 (qqq) equal 1, set q=1q = 1q=1. Then premise 1 is 0⇒1=10 \Rightarrow 1 = 10⇒1=1. Both premises are 1 and conclusion is 0 ⇒ INVALID (affirming the consequent).
  • Class Example 2 (p. 140 left): p∧q, r, s∨T, ¬T, u∨¬r¬r\dfrac{p \land q,\ r,\ s \lor T,\ \neg T,\ u \lor \neg r}{\neg r}¬rp∧q, r, s∨T, ¬T, u∨¬r​.
    1. Make conclusion ¬r=0  ⟹  \neg r = 0 \implies¬r=0⟹ set r=1r = 1r=1 (this also satisfies premise 2, rrr).
    2. Make premise 1 (p∧q=1p \land q = 1p∧q=1) ⇒ set p=1,q=1p = 1, q = 1p=1,q=1.
    3. Make premise 4 (¬T=1\neg T = 1¬T=1) ⇒ set T=0T = 0T=0.
    4. Make premise 3 (s∨T=1s \lor T = 1s∨T=1 with T=0T=0T=0) ⇒ set s=1s = 1s=1.
    5. Make premise 5 (u∨¬r=1u \lor \neg r = 1u∨¬r=1 with ¬r=0\neg r=0¬r=0) ⇒ set u=1u = 1u=1.
    All 5 premises evaluate to 1 while ¬r=0\neg r = 0¬r=0 ⇒ INVALID.
Method B — Rule-of-Inference Derivation (proving validity without a truth table)

Assume the premises are true (1) and apply truth-preserving inference rules step by step. Because every valid rule preserves truth, reaching ccc proves no counterexample row can exist.

5. Predicate Logic & Quantifiers pp. 147–150

Predicate (p. 147): A proposition with variables over a domain of discourse. A predicate gains a truth value only when variables are substituted or quantified.

  • P(x): x=1  ⟹  P(0)P(x):\ x = 1 \implies P(0)P(x): x=1⟹P(0) is false, P(1)P(1)P(1) is true.
  • Q(x,y): x=y+1  ⟹  Q(1,0)Q(x,y):\ x = y+1 \implies Q(1,0)Q(x,y): x=y+1⟹Q(1,0) is true, Q(1,1)Q(1,1)Q(1,1) is false.

Quantifiers p. 148

  • Universal (∀x P(x)\forall x\,P(x)∀xP(x)): P(x)P(x)P(x) holds for all xxx in the domain (one counterexample falsifies it). Ex: ∀x∈Z, x+1>x\forall x\in\mathbb{Z},\ x+1 > x∀x∈Z, x+1>x is true.
  • Existential (∃x P(x)\exists x\,P(x)∃xP(x)): P(x)P(x)P(x) holds for at least one witness xxx in the domain. Ex: ∃x∈R, x2>x\exists x\in\mathbb{R},\ x^2 > x∃x∈R, x2>x is true via witness x=2x=2x=2 (4>24>24>2).

Negating Quantifiers (De Morgan's Laws) p. 149

Pushing ¬\neg¬ across a quantifier switches ∀↔∃\forall \leftrightarrow \exists∀↔∃ and negates the predicate:

¬(∃x P(x))≡∀x ¬P(x),¬(∀x P(x))≡∃x ¬P(x).\neg\bigl(\exists x\,P(x)\bigr) \equiv \forall x\,\neg P(x), \qquad \neg\bigl(\forall x\,P(x)\bigr) \equiv \exists x\,\neg P(x).¬(∃xP(x))≡∀x¬P(x),¬(∀xP(x))≡∃x¬P(x).

Predicate Proof Discipline — Instantiate ∃\exists∃ Before ∀\forall∀ p. 150

Why witness order matters Always unpack an ∃\exists∃ premise first to name a specific witness aaa, then plug that same aaa into ∀\forall∀. (A universal statement holds for every element, including aaa; an arbitrary element chosen first need not satisfy ∃\exists∃.)
