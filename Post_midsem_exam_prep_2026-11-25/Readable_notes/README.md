# Readable CS208 handwritten notes

**All 221 PDF pages transcribed.**

- [Open the browser reader](Readable_notes.html): embedded rendered mathematics and fonts, search, page navigation and a pages 161–221 filter. Formulas remain readable offline and with scripts disabled.
- [Full Markdown transcription](MFOCS_Notes_Readable.md): searchable text using standard `$...$` inline and `$$...$$` display formulas, with the original PDF page numbers.
- [Page index and textbook references](Page_index.md): jump to a topic or source page.

The transcription retains definitions, examples, equations, proof steps, meaningful diagram information, unfinished exercises and administrative notes. Diagrams are explained in words when their layout is not essential; each page links to its original scan. The textbook is used to resolve notation and verify matching definitions/results. Added or restored reasoning is labelled **Textbook clarification**. Unclear handwriting and source issues remain explicitly marked. Topics without a matching section, including the convex-geometry material, are identified as course-specific.

Textbook references use printed Arabic page numbers; add 8 to obtain the textbook PDF page number.

For smaller files: [pages 001–075](parts/Part_01_pages_001-075.md), [076–150](parts/Part_02_pages_076-150.md), [151–205](parts/Part_03_pages_151-205.md), [206–221](parts/Part_04_pages_206-221.md).

The `source_pages/` directory contains source renders, including overlapping crops for long scanned pages. The `reference/` directory contains the searchable textbook extract, page manifest and validation records. The source PDFs remain unchanged.
